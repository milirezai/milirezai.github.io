Architecture

  • Contract-based design: every gateway implements the same interface, so the rest of the app never depends on a specific provider's SDK.
  • An adapter pattern normalizes each gateway's raw response into one consistent response object, regardless of how Zarinpal or Zibal structure their replies.
  • Registered through Laravel's service container and exposed via a facade, so it's used the same way any core Laravel service is.
  • Artisan commands, namespaced under milipay:driver:*, for listing, enabling, disabling, and configuring drivers (default, timeout, retry) from the command line.

FastDriver

When no driver is set explicitly, a scheduled job periodically probes each sandbox gateway and automatically selects whichever one responds fastest — so the app always defaults to the most reliable gateway available at that moment.

A bug worth writing about

The Registry class holding the payment pipeline steps was bound with bind() instead of singleton(). Laravel occasionally clears its Facade resolved-instance cache mid-request — and when that happened inside a queued job, a fresh, empty Registry was created on the next resolve, silently breaking the pipeline.

The fix: bind Registry as a true singleton() so the same instance survives the facade cache clear. I wrote a Persian LinkedIn post on the lesson — Facade caching isn't the same guarantee as a true singleton binding.
